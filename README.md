# 会话附件 · Session attachments

把另一段 DSH 对话带到当前输入框，作为上下文一起发送。适用于 DeepSeek Harness Web / Desktop 0.2.2-rc.5。

直接拖动侧栏里的会话到目标聊天区，或打开来源会话的「⋯」菜单，选择「添加到当前聊天」。不需要先打开来源会话。也可以在输入框单独粘贴完整会话 ID，或打开输入框的「+」菜单，在顶部「添加」分组中选择「文件」下方的「引用会话」。菜单分组适配针对 0.2.2-rc.5；未来版本若改变内部菜单接口，入口可能退回「命令」分组。

会话引用在输入框中显示为图标和标题。成功添加后，输入焦点回到当前草稿末尾，方便接着打字。添加不会发送消息；确认来源、写下问题，再正常发送。没有标题的会话用 ID 显示。把指针移到草稿里的会话标签上，可以核对完整标题、来源目录及 ID；也可以用键盘聚焦「核对会话附件」并按 Enter。此预览只读元数据，不读取对话正文，也不需要在发送前额外确认。

## 发送的是什么？

插件使用 Harness 自带的会话引用，不导出 JSON 文件，也不额外请求模型。目标 agent 开始处理消息时，Harness 会读取来源会话的用户和助手文本，生成标记为不受信任的只读背景快照。图片、工具输出和推理不在快照中。来源后续更新不会同步。默认每条消息最多引用 3 个不同的其他会话；长会话按宿主预算截取。

分享前请确认目标 agent 可以看到这段对话；从来源会话删除文字不会撤回已捕获的快照。

## 安装

从本项目的 GitHub Releases 下载 `local-session-attachments-1.2.1.tgz`，解压到一个打算保留的目录。在 Harness 插件管理中添加解压后包含 `package.json` 的 `package` 目录并启用「会话附件」。本地目录安装后请勿移动或删除该目录。不需要 npm 账号，也不需要运行构建脚本。

## 本地开发

无第三方构建依赖。修改源模块后在包目录运行 `node build.mjs`、`node --check client.js` 和 `node --test`。在插件管理中添加本地包目录即可安装，关闭「会话附件」可停用新增入口。
